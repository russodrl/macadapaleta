Auto-init Example (data attributes)

This section demonstrates declarative init via data-instagram-feed attributes. Set the worker URL above and the widget will auto-initialize.

Feed will appear here when a valid worker URL is configured.

Quick Reference

JavaScript API:
new InstagramFeed({ container: '#el', username: 'macadapaleta', workerUrl: '...', count: 9 }).load();

Data-attribute API:
<div data-instagram-feed data-ig-username="macadapaleta" data-ig-worker="..." data-ig-count="9">

Options: container, username, workerUrl, count, columns, gap, showCaption, showStats, lazyLoad, onLoad, onError, onPostClick
